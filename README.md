# Finance AI App

AI-powered personal finance management platform built with FastAPI and Next.js.

## 🚀 About

Finance AI App is a web application for personal finance management.

The goal is to build an intelligent financial assistant that helps users:

- track income and expenses
- manage budgets
- analyze spending habits
- receive AI-powered financial insights
- improve financial discipline
- achieve long-term financial goals

The long-term vision is to create a Personal CFO powered by AI.

---

- Next.js 16
- React 19
